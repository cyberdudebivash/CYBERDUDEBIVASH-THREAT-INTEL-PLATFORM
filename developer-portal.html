Authentication

Authentication

Two different, mutually exclusive authentication conventions are documented across this repository. Both are shown below rather than choosing one.

Convention A — Bearer token

Authorization: Bearer <key>. Documented in docs/quickstart.html, docs/api-auth-guide.md, docs/faq.html, README.md, and scripts/sentinel_apex_sdk.py.

Convention B — X-API-Key header

X-API-Key: <key>. Documented in api-docs.html ("v200.0").

Key format also varies by source: sa_<key> (api-auth-guide.md, SDK), SA-PRO-<hex> (quickstart.html, faq.html), cdb_pro_/cdb_ent_<hex> (SECURITY.md). apex_openapi_v3.yaml separately documents JWT Bearer auth via POST /auth/login (30-day lifetime) as an alternative to API keys; SECURITY.md separately states JWT tokens are HS256-signed with a 24-hour lifetime, while trust-center.html states RS256. None of this is resolved here — confirm the current convention with enterprise@cyberdudebivash.com before hardcoding integration logic. Full evidence matrix: Documentation Consistency Notice →.

Example Requests

v185.0 FIX: /api/intel?severity=critical (below) was confirmed 404 against the live API -- verified directly with curl, not inferred. Both auth header conventions (Authorization: Bearer and X-API-Key) are real and supported; /api/feed is the one confirmed-working example endpoint, reused for both.

cURL — Bearer token convention

# Fetch the live threat feed
curl -H "Authorization: Bearer YOUR_KEY" \
  "https://intel.cyberdudebivash.com/api/feed"

cURL — X-API-Key convention (api-docs.html)

curl -H "X-API-Key: YOUR_API_KEY" \
  https://intel.cyberdudebivash.com/api/feed

Developer FAQ

Frequently Asked Questions

How do I authenticate API requests?

Sources disagree — see the Authentication section above for both documented conventions.

Can I rotate my API key?

Yes. Email enterprise@cyberdudebivash.com with subject "KEY ROTATION REQUEST" and your reference ID. Your old key remains valid for 7 days during transition. (Source: docs/faq.html)

How do I integrate with Microsoft Sentinel, Splunk, Elastic, or QRadar?

Full platform-specific guides are at onboarding.html: STIX 2.1/TAXII, KQL, SPL, EQL, Sigma, and YARA are all supported. (Source: docs/faq.html)

My API key returns 401 Unauthorized. What's wrong?

Common causes: key copied incorrectly, not yet activated (up to 2 hours after payment), subscription expired, or the key was suspended. Contact enterprise@cyberdudebivash.com. (Source: docs/faq.html)

What you get, and what is enforced

Every figure here comes from the canonical commercial contract and matches the limits the API gateway actually enforces. A published quota can never exceed the enforced one — a build gate fails if it does.

Rate limits are enforced per IP over a 60-second window; daily quotas per API key over a UTC day. Both return HTTP 429 at the cap, which is why no tier is described as unlimited. Uptime is measured as a rolling 30-day percentage of successful API health checks from three independent monitoring locations, with planned maintenance (72h notice) excluded — see the SLA and the live status page.
